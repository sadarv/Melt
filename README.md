# Melt ✦

> 一个本地优先的 AI 伴侣应用，支持自定义角色、记忆系统、日记、备忘录等功能。
> 非专业开发者独立完成，代码简陋在所难免。
---

## 简介

Melt 是一个运行在浏览器里的 AI 伴侣 PWA，支持添加到手机主屏幕使用。只需要一个兼容 OpenAI 格式的 API Key 即可使用，所有数据存储在本地（IndexedDB），不经过任何第三方服务器。

---

## 功能一览

- 💬 **AI 对话** — 支持自定义角色人设、多角色切换
- 🧠 **记忆系统** — 自动提取对话记忆、碎片、时间线、星图
- 📔 **日记** — AI 角色视角日记 + 用户日记
- 📝 **备忘录** — AI 自动生成碎片备忘
- 🌍 **世界书** — 自定义世界观设定注入
- 🗓️ **日程** — AI 角色自动生成每日日程
- 💌 **主动消息** — 设定时间间隔，AI 主动发消息
- 🎨 **聊天主题** — 留白 / 同框 / 液态 / 微信 等多种主题
- 🗺️ **虚拟地图** — AI 生成 SVG 地图
- 📊 **关系图谱** — 可视化关系进度
- 🔒 **锁屏** — 应用内锁屏保护

## 快速开始

### 方式一：直接访问部署好的版本

> 作者部署的公开版本地址（如有）请关注项目主页。

### 方式二：自己部署到 Vercel

1. Fork 本仓库
2. 在 [Vercel](https://vercel.com) 导入项目
3. 构建命令填 `npm run build:lite`，输出目录填 `dist-lite`
4. 部署完成后访问即可

### 方式三：本地运行

```bash
git clone https://github.com/EvenNetR/Melt.git
cd Melt
npm install
npm run dev:lite
```

## 使用配置

首次打开后进入 **设置 → API 配置**，填写：

| 字段     | 说明                                                 |
| -------- | ---------------------------------------------------- |
| API Key  | 你的 OpenAI / 兼容接口的 Key                         |
| API 地址 | 默认 `https://api.openai.com/v1`，使用中转填中转地址 |
| 模型     | 推荐 `gpt-4o-mini` 或任意兼容模型                    |

支持所有兼容 OpenAI 格式的接口（DeepSeek、Claude、本地 Ollama 等）。

**副 API（可选）：** 用于记忆提取、情绪分析等后台任务，建议配置一个便宜的小模型，不配置则与主 API 共用。

## 添加到手机主屏幕（PWA）

**iOS：**

1. Safari 打开部署地址
2. 点击底部分享按钮
3. 选择「添加到主屏幕」

**Android：**

1. Chrome 打开部署地址
2. 点击右上角菜单
3. 选择「添加到主屏幕」或「安装应用」

## 常见问题

**Q: 数据存在哪里？**  
A: 全部存在浏览器的 IndexedDB 里，清除浏览器数据会丢失，建议定期在设置里导出备份。

**Q: 换设备后数据没了？**  
A: 数据是本地的，换设备需要手动导出再导入。

**Q: 支持哪些 AI 模型？**  
A: 支持所有兼容 OpenAI Chat Completions 格式的接口。

**Q: iOS 能收到后台推送通知吗？**  
A: 没有服务端，无法实现真正的后台推送。添加到主屏幕后保持应用在后台运行可以触发主动消息，但关闭后无效。

A: 不可以，见上方协议说明。
